## 退款政策的7个排除条款：哪些情况拿不回钱

V.PS 提供14天退款保证，但只适用于 VPS 产品（域名注册/转移/恢复不退款，SSL 产品有30天退款）。退款通过提交工单申请，不是自动的。每个账户只能退款一次。

**不能退款的情况**（任意一条命中就没法退）：
1. 已经申请过退款（每个账户一生只能退一次）
2. **已用超过 10GB 流量**
3. 有活跃的 BGP 或 IX 服务
4. 服务曾从其他客户转移而来，或转移给其他账户
5. **有滥用报告，或 VPS IP 被列入黑名单**（Spamhaus、blocklist.de、中国 GFW 或其他有合法证据的滥用列表）
6. 已申请 IP 更换
7. **加密货币付款、银行转账付款、续费订单、闪购产品**

第2条"超过10GB流量"是最容易踩的坑。如果你一开机就跑了个大带宽测试、装了 Docker 镜像或同步了点数据，10GB 很快就用完了。测试网络时建议：
- 只跑 ping、traceroute、小文件下载测速
- 不要一次性 apt update && apt upgrade 装一堆软件
- 不要挂 BT 下载或跑流量密集型任务

第5条的"GFW 黑名单"也值得注意——如果你在 VPS 上搭了代理服务被墙了，这台机器就没法退了。

第7条意味着：如果你想保留退款权利，只能用 PayPal 或信用卡付款，不能用支付宝、加密货币或银行转账。续费订单也不能退，所以年付需要更谨慎。

对比一下竞品 GoMami 的退款政策：24小时无风险退款，没这么多限制条件。V.PS 的14天看起来更长，但实际可用性不如 GoMami 的24小时。如果你只是想试试网络质量，月付 + 控制流量在10GB以内 + 用 PayPal 付款，是唯一能保住退款权的组合。

## 不适合谁：三个明确的排除场景

**场景1：你需要跨机房迁移**
V.PS 不支持跨城市迁移。如果买了法兰克福后发现东京更合适，需要重新购买，数据自己迁移，不能直接切换机房。如果你的业务可能需要调整机房位置，这是个硬伤。

**场景2：你买了闪购产品**
闪购产品（Flash Sale）完全不能退款，哪怕在14天内、流量没超10GB也不行。闪购通常价格更低，但等于放弃了所有退款权。

**场景3：你需要高 CPU 性能**
如果你需要跑 CPU 密集型任务（编译、视频转码、机器学习推理），Cloud KVM 入门档的 Intel Xeon 性能一般。第三方测评显示 Unix Bench 单核 592.7 分、双核 1181.7 分，高负载下表现较弱。这种情况建议直接选 Edge 或 Performance 系列的 AMD EPYC。

另外，部分用户在 vpsbenchmarks 上标注过"avoid: does not pay invoices"（避免：不支付账单），但没有进一步说明这是针对什么情况、是否已解决、官方是否有回应。下单前可以自己搜一下最新评价。
